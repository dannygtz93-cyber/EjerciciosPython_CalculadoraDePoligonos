# Calculadora de Polígonos 📐

Una herramienta sencilla de línea de comandos escrita en Python para calcular el área de polígonos (actualmente optimizada para rectángulos y cuadrados).

## 🚀 Características
* Interfaz de usuario simple mediante consola.
* Validación de datos: el programa evita errores si el usuario ingresa texto en lugar de números.
* Cálculo instantáneo basado en base y altura.

## 🛠️ Requisitos
* Python 3.x instalado.

## 📥 Instalación y Uso
1.  Clona este repositorio o descarga el archivo `CalculadoraDePoligonos.py`.
2.  Abre una terminal en la carpeta del archivo.
3.  Ejecuta el script con el siguiente comando:
    ```bash
    python CalculadoraDePoligonos.py
    ```

## 📖 Ejemplo de uso
Al ejecutar el programa, se te solicitarán dos valores:
1.  **Base**: El ancho del polígono.
2.  **Altura**: El alto del polígono.

El resultado se mostrará inmediatamente en pantalla.
