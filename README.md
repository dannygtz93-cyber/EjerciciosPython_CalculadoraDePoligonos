# Calculadora de Polígonos 📐

Aplicación de línea de comandos en Python para calcular el área de diferentes figuras geométricas, diseñada como proyecto de aprendizaje enfocado en buenas prácticas de programación.

---

## 🚀 Características

* Cálculo de áreas para:

  * Rectángulo
  * Triángulo
  * Círculo
* Menú interactivo dinámico.
* Validación de entradas (evita errores por texto o datos inválidos).
* Posibilidad de realizar múltiples cálculos en una sola ejecución.
* Código estructurado en capas:

  * Interfaz (UI)
  * Lógica de negocio
  * Configuración

---

## 🧠 Objetivo del proyecto

Este proyecto fue desarrollado como práctica para:

* Aprender estructuras de control en Python.
* Aplicar modularización del código.
* Implementar validación de datos.
* Introducir conceptos de escalabilidad (agregar nuevas figuras fácilmente).

---

## 🛠️ Requisitos

* Python 3.x

---

## 📥 Instalación

1. Clona este repositorio o descarga el archivo:

```
CalculadoraDePoligonos.py
```

2. Abre una terminal en la carpeta del proyecto.

3. Ejecuta:

```bash
python CalculadoraDePoligonos.py
```

---

## 📖 Uso

1. Selecciona la figura que deseas calcular.
2. Ingresa los valores solicitados (base, altura o radio).
3. El programa mostrará el resultado.
4. Puedes repetir el proceso sin reiniciar el programa.

---

## 🧩 Ejemplo

```
¿Que figura quieres calcular? 1, 2, 3:
1. Rectángulo
2. Triángulo
3. Círculo

Ingresa la base: 5
Ingresa la altura: 10

El área de tu Rectángulo es = 50
```
